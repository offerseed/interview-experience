# VIVO 面经合集

> VIVO 面试经验整理，涵盖算法、开发、硬件、产品等岗位。

## 面试流程概述

VIVO 校招/实习面试通常包含以下环节：

1. **简历投递 + 笔试** — 通过官网或内推投递
2. **技术一面**（约 30 分钟）— 项目经历 + 算法基础
3. **技术二面**（约 30 分钟）— 项目深挖 + 综合能力
4. **HR 面**（约 20 分钟）— 行为面 + offer 沟通

整体节奏较快，部分岗位一面、二面、HR 面会安排在同一天上午连续完成。

## 高频考点

### 算法岗位
- 推荐系统评估指标（NDCG、AUC 的推导过程与区别）
- 损失函数（Focal Loss 的原理与手写实现）
- 多目标任务与业务指标权衡（点赞 vs 评论哪个更重要）
- 手撕代码：NDCG、Focal Loss、数组类题目
- 行为面占比不小：职业规划、优缺点、压力应对、最困难的经历

### 开发岗位
- Java / C++ 基础与数据结构
- Android / 系统底层（终端方向）
- 操作系统 + 计算机网络
- 数据库 + 缓存
