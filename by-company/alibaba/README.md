## 面试流程概述

1. **简历投递** — 通过官网或内推
2. **笔试**（部分岗位）— 编程题
3. **技术一面**（45-60分钟）— 基础 + 编程
4. **技术二面**（45-60分钟）— 项目深挖
5. **交叉面 / 总监面**（30-45分钟）
6. **HR面**（20-30分钟）
