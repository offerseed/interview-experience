## 面试流程概述

百度校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **笔试**（90分钟）— 编程题 + 选择题
3. **技术一面**（45-60分钟）— 基础知识 + 编程题
4. **技术二面**（45-60分钟）— 项目 + 场景设计
5. **技术三面**（30-45分钟）— 综合面
6. **HR面**（20-30分钟）
