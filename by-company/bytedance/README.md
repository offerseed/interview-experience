## 面试流程概述

字节跳动校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 项目深挖 + 技术八股 + 编程题
3. **技术二面**（45-60分钟）— 系统设计 / 深度技术 + 编程题
4. **技术三面**（30-45分钟）— 综合素质 + 部门负责人面试
5. **HR面**（20-30分钟）— 行为面 + 薪资沟通

## 高频考点

### 算法岗位
- 机器学习基础（过拟合、正则化、梯度下降变体）
- 深度学习（CNN、RNN、Transformer、注意力机制）
- NLP / 推荐 / CV 方向知识
- 手撕代码：动态规划、图算法、字符串处理

### 开发岗位
- 计算机网络（TCP/UDP、HTTP/HTTPS、三次握手）
- 操作系统（进程线程、内存管理、IO模型）
- 数据库（索引、事务、锁机制）
- 手撕代码：链表、树、排序、动态规划
