总结 & 建议

  • 这一轮对 Agent 方向的考察比较成体系，不是简单问「用没用过 LangChain」，而是沿着 Agent Loop → Runtime → Harness → Framework → Memory → Tool/Protocol → Sandbox 一路追问
  • 准备 Agent Infra / Agent Runtime / AI 基础设施岗位，除了传统后端八股，建议把 Agent 完整运行链路真正串起来理解
  • MySQL 重点复习事务隔离级别、索引分类、唯一索引与 NULL、联合索引及影响索引使用的常见查询写法
  • LRU 除了写出来，还需要解释数据结构的分工、时间复杂度、最近使用顺序、淘汰逻辑和已有 key 的更新处理
