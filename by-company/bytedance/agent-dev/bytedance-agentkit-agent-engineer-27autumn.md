## 经验总结

整体来看，这一轮对 Agent 方向的考察比较成体系，不是简单问「用没用过 LangChain」，而是会继续往下追：

**Agent Loop 怎么跑 → Runtime 提供什么能力 → Harness 解决什么问题 → Memory 怎么设计 → MCP / Skill 怎么接入 → Sandbox 怎么提供执行环境。**

- 准备类似的 **Agent Infra / Agent Runtime / AI 基础设施** 岗位，除了传统后端八股之外，建议把 Agent 的完整运行链路真正串起来理解一遍。
- MySQL 重点复习事务隔离级别、索引分类、唯一索引与 NULL、联合索引及影响索引使用的常见查询写法。
- LRU 除了写出来，还需要解释数据结构的分工、时间复杂度、最近使用顺序、淘汰逻辑和已有 key 的更新处理。
- MySQL 和算法也不能完全放掉，这轮后半段基本就是比较标准的后端基础考察。
