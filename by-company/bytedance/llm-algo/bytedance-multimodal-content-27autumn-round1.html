总结 & 建议

  • 本面经仅收录面试问题，未提供回答记录
  • 一面整体考察方向：FLUX → Transformer / RoPE → 多维位置编码 → Flow Matching / Flow Shift → MMDiT → 图像 / 视频 VAE → LLM 完整 Forward → Cross-Attention → Agent Skill
  • 整体偏向考察大模型完整技术栈是否真正理解到底层数据流。FLUX 相关不只是问「用过没有」，而是会继续追问到模型结构、位置编码、维度划分、MMDiT 单双流以及 Flow Shift；LLM 也不只是问 Transformer，而是要求能从 Tokenizer 一直讲到 LM Head、Logits 和 Loss；Agent 部分重点考察 Skill 的动态加载、上下文管理以及完整生命周期
  • 典型考察套路：简历上写了这个技术 → 解释整体架构 → 继续追问内部数据流 → 继续追问公式和具体实现细节
