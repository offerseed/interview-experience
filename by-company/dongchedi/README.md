# 懂车帝面经合集

> 懂车帝（字节跳动旗下汽车资讯与交易平台）面试经验整理，涵盖算法、开发、产品等岗位。

## 面试流程概述

懂车帝校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 项目深挖 + 技术八股 + 编程题
3. **技术二面**（45-60分钟）— 系统设计 / 深度技术 + 编程题
4. **技术三面**（30-45分钟）— 综合素质 + 部门负责人面试
5. **HR 面**（20-30分钟）— 行为面 + 薪资沟通

## 高频考点

### 算法岗位
- 推荐 / 搜索 / 广告算法（汽车内容与交易场景）
- 计算机视觉（车辆识别、图像内容理解）
- 机器学习 / 深度学习基础
- 手撕代码：数据结构、动态规划

### 开发岗位
- Java / Go / C++ 基础
- 高并发系统设计
- 数据库 + 缓存
- 消息队列 / 微服务
