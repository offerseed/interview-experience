## 经验总结

- 本场一面以项目深挖和职业交流为主，八股/常规题较少，重点考察对项目细节的理解。
- 面试官给了较多建议：自我介绍要体现「通过项目体现个人能力」而非罗列项目；深入吃透 Agent 框架上下游；表达要自信。
- 消息有序性、上下文压缩阈值是 Agent 场景的常见追问点，建议提前准备。
