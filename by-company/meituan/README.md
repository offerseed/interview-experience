# 美团面经合集

## 面试流程概述

美团校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **笔试**（60-90分钟）— 部分岗位需要在线编程笔试
3. **技术一面**（45-60分钟）— 基础知识 + 编程题
4. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
5. **HR面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 算法岗位
- 机器学习基础 + 深度学习
- 推荐系统 / 搜索 / NLP
- 业务场景题（外卖配送、商家排序）
- 手撕代码：数据结构、算法

### 开发岗位
- Java 基础（JVM、并发、Spring）
- 数据库（MySQL、Redis）
- 分布式系统设计
- 手撕代码：中等难度算法题
