## 一、多目标模型与推荐系统基础

### Q1：讲讲 PLE 的结构

- PLE（Progressive Layered Extraction）是多任务学习模型，在 MMoE 基础上进一步区分共享 Expert 和任务专属 Expert，通过逐层提取的方式实现更清晰的任务分离。
- 标签：核心

### Q2：MMoE 的 embedding 层怎么设计的？

- 考察 MMoE 中 embedding 层的具体实现方式，包括输入特征的 embedding 策略、是否共享 embedding、以及 embedding 维度的设计考量。
- 标签：核心

### Q3：有没有多跳的任务？讲讲 ESMM

- **ESMM**（Entire Space Multi-Task Model）：一种多任务学习框架，通过两个塔分别预测 CTR（点击率）和 CVR（转化率），最终得到 CTCVR = CTR × CVR，解决了 CVR 训练中的样本选择偏差问题。
- 标签：核心

### Q4：模型里面有没有加上序列数据？讲讲 DIN？

- **DIN**（Deep Interest Network）：通过 Attention 机制对用户历史行为序列进行加权聚合，捕捉用户与当前候选广告之间的兴趣相关性。
- 标签：核心

### Q5：DIN 和 Attention 有什么区别？

- DIN 中的 Attention 是 Attention 机制在推荐系统中的具体应用。DIN 的 Attention 用于计算用户历史行为与当前候选广告的相关性权重，而通用 Attention 是一种更广泛的计算权重机制。
- 标签：基础

### Q6：讲讲并联双塔模型怎么实现的？

- 并联双塔模型将用户侧和物品侧分别通过独立的深度网络（塔）编码为向量，然后通过内积或余弦相似度计算匹配分数。在召回阶段效率高，因为物品侧向量可以预计算。
- 标签：核心

### Q7：展开讲讲实习的任务是做什么

- 深挖实习项目经历，考察对实际业务的理解和动手能力。
- 标签：HR/开场

### Q8：In-batch 负采样会样本偏差，怎么纠偏？

- In-batch 负采样的偏差来源于 batch 内正样本对共享相同负样本，导致负样本分布不均匀。
- 纠偏方法：
  1. 增大 batch size
  2. 使用重要采样加权（importance weighting）
  3. 引入全局负样本队列（如 MoCo）
  4. 使用对抗训练或温度系数调节
- 标签：核心

## 二、手撕算法

### Q9：手撕 — 输入前 k 个高频词，次数一样的按照字典序返回

- 示例输入：<code>["i","love","meituan","i","love","coding"]</code>
- 示例输出：<code>["i","love","coding"]</code>（k=3）
- 方法一：用 HashMap 统计词频，再排序，时间复杂度 <code>O(n log n)</code>。
- 方法二：用最小堆（大小为 k），维护 top-k 高频词，再对堆中元素按字典序排序，时间复杂度 <code>O(n log k)</code>。
- 标签：核心

这轮面试时长约半小时，节奏紧凑，考察 **多任务学习模型 + 推荐系统基础 + 手撕算法**。

- 面试围绕 **PLE → MMoE → ESMM → DIN → 双塔模型** 的推荐系统主线展开，覆盖了多目标、多任务、序列建模、召回等核心模块。
- PLE 和 MMoE 的结构差异、embedding 设计是多任务学习的面试高频考点，需要深入理解。
- ESMM 解决了多任务学习中的样本选择偏差问题，是推荐系统面试的经典模型。
- In-batch 负采样的偏差问题考察对训练技巧的深度理解，需要知道多种纠偏方案。
- 手撕题考察 Top K 高频词，两种解法（排序 O(n log n) vs 堆 O(n log k)）都要掌握。
- 实习项目的细节需要非常熟悉，面试官要求"展开讲讲"说明想了解深度。
