## 高频考点

### 智能驾驶
- 感知算法（BEV、多模态融合、Occupancy）
- 规划与控制（Motion Planning）
- 自动驾驶系统架构
- C++ 编程

### 算法岗位
- 机器学习 + 深度学习
- 多模态大模型应用
- 推荐系统
- Python / C++ 编程

### 开发岗位
- C++ / Java / Go 基础
- 嵌入式系统 / 车载系统
- 实时系统设计
- 操作系统 + 网络
