面试流程

一面 — 工程基础与岗位匹配度
Q: 请先做一个简单的自我介绍。 开放题
本硕背景，研究方向围绕 AI 与大模型。有两段实习经历。期待加入蔚来。
Q: 到上海安亭实习，通勤是否有困难？能实习多久，每周出勤几天？ 开放题
通勤没有问题，之前实习的通勤距离也比较长。每周可以出勤四天，实习六个月以上。
Q: 简历上写 Python 使用很精通，能解释一下 GIL 是什么吗？ 基础
不太了解 Python 的 GIL。
Q: 学过 C++ 吗？是否用 C++ 搭建过项目或工程？ 基础
对 C++ 有一定了解。第一段实习主要围绕 C++ 和 CUDA 展开，工作以调试 bug 为主，没有用 C++ 搭建过完整项目。
Q: Python 装饰器的原理是什么？ 基础
装饰器用于装饰函数，知道函数套函数的写法和语法糖的写法，但对具体原理不够熟练。
Q: 为什么叫语法糖？它有什么作用？ 基础
主要作用是让代码编写更加便捷。例如使用装饰器时可以直接在函数前写装饰器，不必额外编写复杂的调用代码。
Q: 一个分支要合并到主线，出现文件冲突时，你的解决流程是什么？ 基础
平时会借助 AI 查询对应操作，确认命令语法后按步骤执行，没有系统梳理过独立解决合并冲突的完整流程。
Q: 了解 Git worktree 吗？ 基础
听到后确认是否指工作树，但对具体概念和用法不太了解。
Q: 知道 Git cherry-pick 吗？ 基础
不了解。
Q: 平时使用过 Vim 吗？ 基础
没有使用过。
Q: 把一个计算任务交给 GPU，再拿到结果，完整的 CUDA 计算流程是什么？ 核心
对完整链路不够熟悉。理解是先在 CUDA 算子中处理显存、线程等基础工作，再进行上层封装，最后通过 Python 调用。无法清晰说明任务如何输入、拆分、执行以及结果如何返回。面试官反馈：用 C++ 编写 CUDA 时这属于基础流程。
Q: 是否系统学过数据结构与算法？了解哈希表吗？ 基础
自学过数据结构与算法，但没有完全学完。对哈希表只了解基本概念，不够熟练。
Q: 平时使用哪些在线编程产品？ 开放题
会使用 Codex 搭建代码框架，再在此基础上完善工作。
Q: 学过操作系统相关知识吗？ 基础
没有学过操作系统相关知识。
Q: 对岗位的工程属性是否了解？是否愿意考虑其他算法组？ 开放题
面试官介绍：团队是工程部门，主要做前后端、引擎等传统开发，也涉及模型训练部署相关工程、训练框架优化和千卡集群调度。面试官反馈：当前背景与岗位需求不太匹配，基础问题回答不够扎实，愿意推荐至其他算法组。
Q: 反问——我是通过什么渠道进入这次面试的？ 开放题
面试官回答：通过 BOSS 直聘获取简历并主动邀约。认可学历和背景，愿意向其他算法组推荐并提供面试机会。

总结 & 建议

  • 先核实岗位职责：虽归类为 Agent 开发，本次实际考察集中在工程基础，没有涉及 Agent 架构或算法推导
  • 简历中的精通、熟练需要能够支撑：面试官直接围绕 Python、Git、CUDA 的熟练程度追问
  • 补齐 Python 与 Git 基础：重点复习 GIL、装饰器、语法糖；练习分支合并、冲突处理、worktree 与 cherry-pick
  • 从局部 CUDA 调试补到完整流程：通过最小 C++ CUDA 示例梳理显存分配、数据传输、kernel 启动、同步、结果取回
  • 系统学习计算机基础：补齐数据结构与算法、哈希表和操作系统知识
