## 经验总结

- **先核实岗位职责**：虽然归类为 Agent 开发、岗位名称包含 AI，本次实际考察集中在工程基础，没有涉及 Agent 架构或算法推导。接受邀约时应先确认部门职责、技术栈与实习生的具体工作，尤其是招聘方主动联系的情况。
- **简历中的“精通”“熟练”需要能够支撑**：面试官直接围绕 Python、Git、CUDA 的熟练程度追问。简历应准确区分“使用过”“修改过局部代码”和“能独立开发、解释完整流程”。
- **补齐 Python 与 Git 基础**：重点复习 GIL、装饰器和语法糖；亲手练习分支合并、冲突处理、worktree 与 cherry-pick，理解命令的作用和执行结果。
- **从局部 CUDA 调试补到完整流程**：做过算子修改并不代表能解释端到端的 GPU 计算。后续可通过一个最小 C++ CUDA 示例，梳理显存分配、数据传输、kernel 启动、同步、结果取回、错误检查和资源释放。这是复习建议，并非当场回答。
- **系统学习计算机基础**：补齐数据结构与算法、哈希表和操作系统知识。依赖 AI 查询操作或搭建框架之外，也要能独立解释代码与工具的工作方式。
- **面试氛围较温和，反馈直接**：面试官在多次回答不熟悉后仍继续了解经历，明确解释岗位不匹配的原因，并表示愿意推荐算法组。当前记录只说明推荐意向，不能视为已进入其他组的面试流程。
