Q: ReAct 整体模块怎么写？

代码怎么实现？

Q: ReAct 中消息怎么传？
system、user、assistant、tool 等角色如何组织？

Q: Agent 循环什么时候停止？
最大轮数
token 预算

Q: SFT 的损失函数是什么？
考点：通常是自回归交叉熵 / 负对数似然；Adam 是优化器，不是损失函数。
Q: 推理多样性怎么控制？
top-k、top-p、temperature 的作用
底层如何根据下一个词概率进行采样
Q: 大模型支持的上下文长度由哪些因素决定？
预训练长度
位置编码与外推能力
显存和 KV cache
注意力实现、批大小等
Q: vLLM 做推理加速时做了哪些优化？
PagedAttention
Continuous Batching
KV cache 分块管理
Prefix Caching / 前缀共享
减少显存碎片，提高吞吐
Q: RAG 分块召回不好，有哪些优化策略？
先看答案是否在知识库 / 向量库
检查切块粒度、语义切分、父子分块
稀疏检索 + 稠密检索混合
query 改写
元数据过滤、权限 / 时间标签
重排
多库区分，避免混库
手撕代码
Q: 最大连续子数组和
考点：Kadane 算法 / 动态规划
一边遍历即可完成
状态转移：dp[i] = max(nums[i], dp[i-1] + nums[i])
Q: 岛屿数量
考点：二维网格 DFS / BFS
遍历每个点，遇到陆地就计数，并淹没相邻陆地
注意边界条件、二维数组长宽获取、递归 / 队列实现
