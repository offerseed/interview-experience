## 面试流程概述

深信服校招/实习面试通常包含以下环节：

1. **简历投递 + 笔试** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 基础八股 + 项目 + 编程题
3. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
4. **HR 面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 安全岗位
- 网络安全基础（TCP/IP、常见攻防手段、漏洞原理）
- 操作系统与计算机网络
- 安全产品与场景（防火墙、EDR、SASE、零信任）
- 密码学基础

### 开发岗位
- C / C++ / Go / Python 基础
- 高并发与网络编程
- Linux 内核 / 虚拟化 / 容器
- 数据库 + 缓存

### 算法岗位
- 机器学习 / 深度学习基础
- 安全场景算法（威胁检测、异常流量识别）
- NLP / 图算法
