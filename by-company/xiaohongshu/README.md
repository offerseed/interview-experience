## 面试流程概述

小红书校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 基础 + 编程题
3. **技术二面**（45-60分钟）— 项目 + 场景设计
4. **技术三面 / 总监面**（30-45分钟）
5. **HR面**（20-30分钟）
