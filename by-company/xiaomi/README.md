## 面试流程概述

小米校招/实习面试通常包含以下环节：

1. **简历投递 + 笔试** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 基础八股 + 项目 + 编程题
3. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
4. **技术三面 / 总监面**（30-45分钟）— 综合能力
5. **HR 面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 算法岗位
- 推荐 / 搜索 / 广告算法（小米商城、MIUI 内容与商业化场景）
- 计算机视觉 / 多模态（手机影像、自动驾驶感知）
- 大模型与端侧模型（端侧部署、模型压缩）
- 手撕代码：数据结构、动态规划

### 开发岗位
- Java / C++ / Go / Python 基础
- Android / 系统底层（MIUI、HyperOS）
- 高并发系统设计
- 数据库 + 缓存

### 硬件 / 嵌入式
- 电路基础与嵌入式 C
- 操作系统与驱动开发
- 传感器 / 通信协议
