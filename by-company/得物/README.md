## 面试流程概述

得物校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（20-30分钟）— 项目 + 推荐系统基础
3. **技术二面**（20-30分钟）— 项目深挖 + 手撕代码
4. **技术三面**（20-30分钟）— 综合面 + 职业规划
5. **HR面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 算法岗位
- 推荐系统全链路（多路召回 → 粗排 → 精排 → 重排）
- 多目标优化（极化现象、跷跷板现象及其解决方案）
- 生成式推荐（beam search + 前缀树解码、RQ-VAE 残差量化）
- 向量检索（Faiss、双塔模型、CF/MF）
- 手撕代码：数组查找、双指针、动态规划

### 开发岗位
- Java / Go / C++ 基础
- 高并发系统设计
- 数据库 + 缓存
- 电商交易与风控场景
