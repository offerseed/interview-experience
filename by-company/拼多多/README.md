# 拼多多面经合集

> 拼多多面试经验整理，涵盖算法、开发、产品等岗位。

## 面试流程概述

拼多多校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **笔试**（60分钟）— 编程题
3. **技术一面**（45-60分钟）— 基础 + 编程
4. **技术二面**（45-60分钟）— 深度项目 + 设计
5. **HR面**（20-30分钟）
