## 面试流程概述

腾讯校招/实习面试通常包含：

1. **笔试/简历筛选** — 部分岗位需要笔试
2. **技术一面**（45-60分钟）— 基础知识 + 编程题
3. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
4. **总监面/GM面**（30-45分钟）— 综合能力
5. **HR面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 技术岗位
- C++ 基础（内存管理、STL、虚函数、智能指针）
- 计算机网络（TCP三次握手/四次挥手、拥塞控制）
- 操作系统（进程间通信、虚拟内存、文件系统）
- 数据库（MySQL 索引、事务隔离级别）
- 编程题：数据结构、算法基础

### 算法岗位
- 机器学习基础 + 深度学习
- 推荐系统 / NLP / CV
- 大模型相关（微调、RAG、Agent）
