> 蚂蚁集团（含支付宝、数字支付、数字金融、OceanBase 等）面试经验整理，涵盖算法、开发、数据、安全等岗位。

## 面试流程概述

蚂蚁校招/实习面试通常包含以下环节：

1. **简历投递 + 笔试** — 通过官网或内推投递（笔试难度较高）
2. **技术一面**（45-60分钟）— 基础八股 + 项目 + 编程题
3. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
4. **技术三面 / 交叉面**（45-60分钟）— 深度技术 + 综合能力
5. **HR 面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 算法岗位
- 风控与反欺诈算法（图算法、异常检测、序列建模）
- 推荐 / 搜索算法（支付宝内容与营销场景）
- 机器学习 / 深度学习基础，大模型应用
- 手撕代码：数据结构、动态规划、图算法

### 开发岗位
- Java 基础与 JVM、并发编程
- 分布式系统（一致性、分布式事务、CAP）
- 高并发与性能调优（双十一场景）
- 数据库（OceanBase、MySQL）+ 缓存 + 消息队列

### 基础架构 / 数据
- 分布式存储与数据库内核
- 云原生（K8s、Service Mesh）
- 实时计算（Flink）+ 数仓建模

### 安全岗位
- 网络安全、应用安全、数据隐私合规
- 密码学基础
- 风控对抗与黑产识别
