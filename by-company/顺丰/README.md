# 顺丰面经合集

> 顺丰（含顺丰科技、丰巢、供应链体系）面试经验整理，涵盖算法、开发、数据、产品等岗位。

## 面试流程概述

顺丰校招/实习面试通常包含以下环节：

1. **简历投递 + 笔试** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 基础八股 + 项目 + 编程题
3. **技术二面**（45-60分钟）— 项目深挖 + 系统设计
4. **技术三面 / 总监面**（30-45分钟）— 综合能力
5. **HR 面**（20-30分钟）— 行为面 + offer 沟通

## 高频考点

### 算法岗位
- 运筹优化 / 路径规划（车辆调度、末端配送、网络规划）
- 推荐 / 搜索算法（物流场景的供需匹配）
- 机器学习 / 深度学习基础，时序预测（单量预测）
- 手撕代码：图算法、动态规划、贪心

### 开发岗位
- Java / Go / C++ 基础
- 高并发系统设计（订单、运单、轨迹）
- 消息队列 / 分布式事务
- 数据库 + 缓存

### 数据岗位
- SQL / 数仓建模（Hive、Spark）
- 实时计算（Flink）
- 指标体系与业务分析
